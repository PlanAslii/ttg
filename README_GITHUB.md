## English

**Vira** collects and publishes tested V2Ray-compatible configurations (VLESS, VMess, Trojan, Shadowsocks) from multiple public sources.

- Channel: [t.me/viraconfigs](https://t.me/viraconfigs)
- Bot (get by country / protocol): [@vira_boxbot](https://t.me/vira_boxbot)

Configs in this repository are refreshed automatically (typically every ~30 minutes) from the last hour of verified working links.

### How to use

1. Install a client: **v2rayNG** (Android), **V2RayN** / **Hiddify** (Windows), **Streisand** / **Shadowrocket** (iOS), etc.
2. Add a **subscription** URL (e.g. `all.txt` or a country file).
3. Update the subscription and connect.

Or open [@vira_boxbot](https://t.me/vira_boxbot), pick country/protocol, and get a filtered list.

### Repository layout

```text
all.txt                 Full list (recent working configs)
countries/XX.txt        By country code (IR, NL, DE, …)
protocols/vless.txt     VLESS only
protocols/vmess.txt     VMess only
protocols/trojan.txt    Trojan only
protocols/ss.txt        Shadowsocks only
```

### Notes

- Connectivity tests run on servers **outside Iran**; a config may look online but still be filtered by some ISPs.
- Iranian hosts may include a nimbaha marker in the remark name (`🟢` / `🔴`) when applicable.
- This repo is for **personal use** and educational aggregation of publicly shared configs. Use responsibly and respect local laws.
